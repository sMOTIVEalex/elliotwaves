# 1 · Impulse und Zählregeln

Ein klassischer Impuls unterteilt sich in **5–3–5–3–5**. Die Zahlen zeigen die Struktur der fünf Teilwellen auf dem nächstkleineren Wellengrad. Die 3 steht für eine korrektive Struktur, die auch komplex sein kann. Die Beispiele gelten für einen Aufwärtsimpuls. Beim Abwärtsimpuls spiegeln sich die Richtungen. [Elliott Wave International, Impulse](https://www.elliottwave.com/waveopedia/impulse/)

## Harte Regeln für den klassischen Impuls

| Regel | Aufwärtsimpuls im Chart |
| --- | --- |
| **Welle 2 bleibt vor dem Ursprung von Welle 1.** | Sie darf tief in den Kursbereich von Welle 1 zurücklaufen. Erreicht sie den Start von 1, entspricht das einem Rücklauf von 100 % und der klassische Count ist ungültig. |
| **Welle 3 muss das Ende von Welle 1 übertreffen.** | Das Ende von 3 liegt über dem Hoch von 1. |
| **Welle 3 darf von 1, 3 und 5 nicht die kürzeste sein.** | Vergleiche die Preisstrecken jeweils vom eigenen Start bis zum eigenen Ende. Welle 1 oder 5 kann länger sein als Welle 3. |
| **Welle 4 darf den Preisbereich von Welle 1 nicht betreten.** | Prüfe bei einem aufwärts gerichteten Impuls den Kursbereich der gesamten Welle 4 gegen das Hoch von 1. Eine Unterschreitung verletzt die Regel. |

Beim Überlappen von 1 und 4 kommt eine **Diagonale** infrage, falls Position und innere Struktur passen. Eine *Leading Diagonal* ist in Welle 1 oder A eines Zigzags möglich. Eine *Ending Diagonal* liegt meist in Welle 5 und kann in C auftreten. Welle 3 eines Impulses unterteilt sich selbst als Impuls. [Elliott Wave International, Motive Waves](https://www.elliottwave.com/waveopedia/motive-waves/) · [Impulse](https://www.elliottwave.com/waveopedia/impulse/) · [Diagonals](https://www.elliottwave.com/waveopedia/elliott-wave-pattern-diagonals/)

## Typische Richtwerte für Wellen 1–5

| Welle | Form und erste Kursmarken |
| --- | --- |
| **1** | Erster Schub eines möglichen neuen Trends. Ein Fünfer kann vorläufig auch A eines Zigzags sein. Für die absolute Länge von 1 gibt es kein festes Prozentziel. Sobald ihr Ende plausibel ist, liefert ihre Länge die Messbasis für 2, 3 und gegebenenfalls 5. |
| **2** | Rücklauf gegen 1. Zuerst **50–61,8 %** der Länge von 1 prüfen. **38,2 %** ist ein Beispiel für einen flacheren Rücklauf. |
| **3** | Vom Ende von 2 aus **1,618 × Länge von 1** als erste Projektion. Für stärkere Extensions **2,618 ×**, als weit entfernte Referenz **4,236 ×**. |
| **4** | Gegenbewegung nach 3. Vom Ende von 3 aus zunächst **23,6–38,2 %** der Länge von 3 zurückmessen. **50 %** ist eine tiefere Referenz, sofern die Überlappungsregel eingehalten wird. |
| **5** | Bei verlängerter 3 zunächst **1,0 × Länge von 1** ab Ende von 4 prüfen. Als Ansatz für eine mögliche verlängerte 5 lassen sich **0,618 × oder 1,0 ×** der Nettostrecke vom Start von 1 bis zum Ende von 3 ab Ende von 4 projizieren. |

Eine **Extension** ist eine preislich verlängerte, intern weiter unterteilte Welle 1, 3 oder 5. Die Unterwellen und der Vergleich zu den anderen Schüben geben den Ausschlag. Bei einer seltenen **verkürzten Welle 5** bleibt ihr Ende vor dem Extrem von Welle 3. Dafür sollte die innere Fünferstruktur erkennbar sein. [Elliott Wave International, Extension](https://www.elliottwave.com/waveopedia/extension/) · [Truncation](https://www.elliottwave.com/waveopedia/truncation/)

Die Prozentwerte stammen aus klassischen Projektionen und Lehrbeispielen. **50 %** ist ein gebräuchlicher Mittelwert. Die Marken lassen sich als mögliche Zielbereiche lesen. Die Zählregeln gelten unabhängig davon, welche Marke erreicht wird. ## Beispiel mit linearen Kursen

1. **Welle 1:** 100 → 120. Die Preisstrecke beträgt 20 Punkte oder 20 % vom Startkurs.
2. **Welle 2:** 61,8 % Rücklauf liegen bei 120 − 0,618 × 20 = **107,64**.
3. **Welle 3:** Bei einem Ende von 2 bei 107,64 liegt die 161,8-%-Projektion bei 107,64 + 1,618 × 20 = **140,00**.
4. **Welle 4:** Endet 3 bei 140,00, liegt ein Rücklauf von 38,2 % dieser Welle bei 140 − 0,382 × (140 − 107,64) ≈ **127,64**. Das Hoch von 1 bei 120 bleibt darunter.
5. **Welle 5:** Endet 4 bei 127,64, liegt die Gleichheitsprojektion mit Welle 1 bei 127,64 + 20 = **147,64**.
