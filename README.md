# Elliott-Wellen · Kurzreferenz

Ein klassischer Impuls hat fünf Wellen. **1, 3 und 5** laufen mit dem Impuls, **2 und 4** korrigieren ihn. Nach Welle 5 kann eine Korrektur des gesamten Fünfers auf dem nächsthöheren Wellengrad folgen.

**Faustwerte für den Einstieg.** Welle 2 bei **50–61,8 % von Welle 1** prüfen. Welle 3 ab Ende von Welle 2 mit **161,8 % der Länge von Welle 1** projizieren. Für Welle 4 zuerst **23,6–38,2 % von Welle 3** prüfen. Bei verlängerter Welle 3 für Welle 5 als Erstes die **Länge von Welle 1** ab Ende von Welle 4 abtragen. Die Struktur und ihre Invalidation entscheiden über die Zählung.
